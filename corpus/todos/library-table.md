# Library table

The page with every book in a table: multi-column sort, a filter on every column
by kind (text, pick-list, range, yes/no) with chips for active filters, one
diacritics-insensitive search box, column show/hide/reorder/resize remembered
per device, cover thumbnails, virtual scrolling. A Covers view (a cover grid,
the phone default) shows the same rows. Look and layout:
[design.md](../wiki/design.md).

## Context

The owner asked for a table of all books that can be sorted and filtered "by any
column". Design in [library-table.md](../wiki/library-table.md).

## Acceptance

Every column can be sorted and filtered.
